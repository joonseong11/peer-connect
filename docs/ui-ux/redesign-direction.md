# Peer Connect UI/UX Redesign Direction

## 목표

현재 Peer Connect를 일반적인 카드형 SaaS가 아니라, 초대 기반 개발자 커뮤니티에 맞는 "신뢰 중심 네트워크 제품"으로 재정의한다.

## 내가 추천하는 방향

### 방향명

Private Technical Salon

### 한 줄 설명

과하게 스타트업스럽지도, 차갑게 엔터프라이즈스럽지도 않은 톤. 믿을 만한 사람들과 깊이 교류하는 “작지만 밀도 높은 기술 살롱”의 느낌으로 간다.

### 이 방향을 추천하는 이유

- 이 서비스의 본질은 대규모 공개 커뮤니티가 아니라 신뢰 기반의 폐쇄형 연결이다.
- 현재 UI의 문제는 미완성이라기보다 너무 일반적이라는 점이다.
- 화려한 블록형 커뮤니티 스타일보다, 신뢰감 있는 편집적 레이아웃과 명확한 정보 계층이 더 오래 간다.

## 리디자인 원칙

### 1. 페이지 역할이 바로 느껴져야 한다

페이지 첫 화면에서 사용자는 즉시 아래 중 하나를 느껴야 한다.

- 둘러보는 화면
- 사람을 평가하는 화면
- 글을 작성하는 화면
- 내 상태를 관리하는 화면

같은 카드 구조를 반복하지 말고, 페이지 목적에 맞게 리듬을 달리해야 한다.

### 2. 신뢰 신호를 텍스트보다 먼저 보이게 한다

멤버, 추천, 모임, 초대는 모두 신뢰와 관계의 문제다. 따라서 긴 설명보다 아래 정보가 먼저 보여야 한다.

- 누구인가
- 어떤 분야인가
- 얼마나 활동 중인가
- 왜 믿을 수 있는가
- 지금 어떤 액션을 하면 되는가

### 3. 제품 내부가 랜딩보다 더 좋아 보여야 한다

지금은 랜딩이 제품보다 더 브랜디드되어 있다. 개편 후에는 로그인 이후가 오히려 더 매력적이어야 한다.

### 4. 유리 카드보다 표면 체계를 재설계한다

유리 효과는 포인트로만 쓰고, 기본 표면은 더 단단해야 한다.

권장 구조:

- 페이지 배경: 따뜻한 라이트 뉴트럴
- 주 표면: 종이 같은 솔리드 카드
- 강조 표면: 진한 잉크색 패널 또는 옅은 색 블록
- 인터랙션 표면: 호버 시만 미세한 상승과 색 변화

## 비주얼 시스템 제안

### 컬러

지금의 인디고 중심 팔레트는 너무 익숙한 SaaS 문법에 가깝다. 아래처럼 더 차분하고 인간적인 팔레트가 좋다.

- Ink: `#14213D`
- Paper: `#FFFDF8`
- Stone: `#ECE7DF`
- Forest Accent: `#1F6B57`
- Amber Accent: `#C67C2E`
- Danger: `#B42318`

사용 규칙:

- 메인 강조는 Forest 하나로 좁힌다.
- Amber는 초대, 배지, 중요 메타 같은 신뢰 포인트에만 쓴다.
- 배경은 백색이 아니라 약간 따뜻한 Paper 계열로 바꾼다.

### 타이포그래피

한국어 환경에서는 과한 디스플레이 폰트보다 안정적인 서체 조합이 중요하다.

권장:

- Headings: `SUIT Variable`
- Body: `Pretendard Variable`
- Meta / code / invite code: `JetBrains Mono`

규칙:

- 헤딩은 더 크고 더 조밀하게
- 본문은 지금보다 줄 길이를 줄이고 행간을 약간 더 넓게
- 메타 정보는 모노를 써서 “시스템성”을 분리

### 형태

- 기본 라운드값을 지금보다 줄인다.
- 모든 카드를 `3xl`로 통일하지 않는다.
- 핵심 카드만 크게, 보조 카드는 더 단단하게 처리한다.

권장 반경 체계:

- Hero / 강조 패널: 28px
- 기본 카드: 20px
- 인풋 / 세그먼트 / 배지: 14px

### 모션

- 페이지 첫 진입 시 짧은 위상 정리 애니메이션
- 카드 hover는 이동보다 색/그림자 변화 비중을 높임
- 저장/성공 상태는 토스트 또는 인라인 체크 모션으로 통일

## 정보 구조 개편

### 글로벌 네비게이션

현재보다 제품의 영역을 명확하게 나눈다.

- 둘러보기
- 모임
- 네트워크
- 내 활동

보조 규칙:

- 상세 페이지에는 breadcrumb 또는 부모 링크를 더 명확히 준다.
- 마이페이지 안에는 로컬 탭 또는 서브네비를 둔다.

### 로그인 전 / 후 홈 분리

이건 우선순위가 높다.

- 로그인 전: 브랜드/초대/가치 중심 랜딩
- 로그인 후: 활동 피드, 추천 요청, 최근 모임, 네트워크 추천이 보이는 멤버 홈

같은 `/`에서 분기해도 되고, 별도 멤버 홈을 만들어도 된다.

## 화면별 개편 제안

### 1. 랜딩

핵심 방향:

- 더 적은 카드, 더 강한 메시지
- 실제 멤버/추천/모임의 밀도를 보여주는 신뢰 섹션 강화
- 커뮤니티를 “따뜻한 기술 네트워크”로 보이게 할 것

구성 제안:

1. Hero
2. 실제 커뮤니티 신호: 추천 수, 모임 수, 멤버 직군 분포
3. 멤버 프로필 샘플
4. 모임/교류 샘플
5. 초대 기반 운영 원리
6. 가입 CTA

### 2. 멤버 목록

카드 그리드만 두지 말고 디렉터리로 바꾼다.

추가 요소:

- 역할/관심사/활동 태그
- 추천 수
- 최근 활동
- 필터와 정렬
- “지금 연결해볼 만한 멤버” 추천 섹션

### 3. 멤버 상세

상단은 프로필 요약 hero로, 하단은 신뢰 섹션으로 나눈다.

권장 블록:

- 상단 hero: 이름, 역할, 한 줄 소개, 핵심 태그, 추천 수
- 왼쪽: 프로필 핵심 정보
- 오른쪽: 연락처, 최근 활동, 추천 요청 CTA
- 하단: 추천서 피드

### 4. 모임 라운지

게시판에서 커뮤니티 라운지로 바꾼다.

추가 요소:

- 상태 구분: 모집 중, 진행 예정, 종료 후 회고
- 포맷 태그: 커피챗, 스터디, 세미나, 사이드프로젝트
- 보기 전환: 카드 / 리스트
- 상단에 큐레이션 섹션

### 5. 모임 상세

현재는 긴 글 + 댓글 구조다. 여기에 “참여 판단”을 돕는 정보가 먼저 와야 한다.

상단 블록 추천:

- 모임 제목
- 주최자
- 모임 포맷
- 기대하는 사람
- 참여 방식

댓글은 하단 커뮤니티 반응 영역으로 분리한다.

### 6. 프로필 작성

긴 폼을 그대로 두지 말고 작성 여정을 설계한다.

권장 구조:

- 기본 정보
- 커리어/소개
- 링크/연락처
- 완료도 표시

보완:

- 예시 입력 강화
- 저장 시 실시간 진행률
- "이 정보가 어떻게 보여지는지" 미리보기 제공

### 7. 마이페이지

단순 허브가 아니라 개인 대시보드가 되어야 한다.

우선 노출 정보:

- 프로필 완성도
- 받은 추천 수
- 최근 모임 활동
- 초대 가능 상태
- 다음 행동 1개

### 8. 초대 관리

초대는 이 서비스만의 고유 기능이다. 지금보다 훨씬 브랜디드되어야 한다.

강화 포인트:

- 초대 슬롯을 실제 자산처럼 보이게
- 누구를 초대했는지 관계 맥락 표시
- 사용 가능/사용 완료/연결 완료 상태를 더 명확하게 구분

## 1차 개편 우선순위

### P1

- 글로벌 디자인 토큰 재정의
- 헤더/푸터/공통 버튼/공통 표면 체계 정리
- 로그인 전 홈과 로그인 후 홈 분리

### P2

- 멤버 목록/상세 리디자인
- 모임 목록/상세 리디자인
- 마이페이지를 개인 대시보드로 개편

### P3

- 프로필 작성 폼 단계화
- 초대 관리 고도화
- 설정/위험 구역/빈 상태/토스트 체계 정리

## 구현 방식 제안

리디자인은 한 번에 전면교체하지 말고 아래 순서로 가는 게 안전하다.

1. 토큰과 공통 컴포넌트부터 바꾼다.
2. 홈, 멤버, 모임처럼 영향이 큰 화면부터 바꾼다.
3. 작성/설정/초대 같은 생산성 화면은 두 번째 라운드에서 맞춘다.
